summary: "You have connected a [Power BI semantic model](https://learn.microsoft.com/en-us/fabric/data-science/semantic-model-best-practices) to a [Fabric Data Agent](https://learn.microsoft.com/en-us/fabric/data-science/concept-data-agent), and now you want to explain that People means Customers and Revenue means Net Sales Amount. Several configuration names sound relevant: [AI instructions](https://learn.microsoft.com/en-us/power-bi/create-reports/copilot-prepare-data-ai-instructions), [Data Agent instructions and data-source instructions](https://learn.microsoft.com/en-us/fabric/data-science/data-agent-configurations), and [example queries](https://learn.microsoft.com/en-us/fabric/data-science/data-agent-example-queries). Should you repeat the explanation everywhere to be safe? I would not take that approach, because these capabilities have different responsibilities and are not all available for semantic models. The useful distinction is between [preparing the semantic model for AI](https://learn.microsoft.com/en-us/power-bi/create-reports/copilot-prepare-data-ai) and configuring the agent that decides when to use it."
