Microsoft Fabric closes that gap with data agents: configurable, read-only conversational layers over lakehouses, warehouses, Power BI semantic models, and KQL databases. Connecting a Fabric data agent into Copilot Studio as a connected agent lets a custom Copilot Studio agent hand off data questions to Fabric while keeping the conversation, orchestration, and channel deployment in Copilot Studio.  This article walks through what a Fabric data agent actually does, how the Copilot Studio connection works step by step, what governance changes the moment data leaves Fabric's compliance boundary, and a grounded estimate of what the whole setup costs to run at enterprise scale."
