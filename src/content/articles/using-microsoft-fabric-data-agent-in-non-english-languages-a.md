Rather than stopping at the official \"English-first\" guidance, it presents three pragmatic patterns for enabling multilingual experiences today: English instructions with translate-in/translate-out behavior, Copilot Studio as a multilingual front-end, and a translation gateway built around the Data Agent API. The goal is to help teams choose the right architecture for multilingual adoption without overestimating native language support."
